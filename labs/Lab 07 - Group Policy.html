Introduction to Group Policy Management

We will start this lab by simply creating a new GPO and applying basic settings to an OU. We will also explore the provided tools and various Group Policy Management functions and use cases.

Create a new GPO and Link to an OU

  • On DC1-2017-####, from Server Manager, open the Group Policy Management console.
  • Expand the forest, the domains, and select Group Policy Objects under your comp2017-####.local domain. You should see your existing domain policies.
    • Examine the default GPOs and observe what these are linked to (the scope where they are being applied).
      • Under Group Policy Objects, select the Default Domain Policy. Under the Scope tab, you should see what is linked to this policy
      • Select the Settings tab, expand Computer Configuration (Enabled), Windows Settings, and Security Settings by clicking on the show link on the right side to observe the account policy and password configuration changes you made in the previous lab.
    • You can also right-click on each object to see what actions you can take and what can be modified. Do not modify anything at this point; just explore to familiarize yourself with this interface.
  • Create a new GPO named Sales GPO:
    • Right-click Group Policy Objects and select New, enter the name as Sales GPO, and click OK.
  • Edit the new Sales GPO by right-clicking on the object and choosing Edit.... The Group Policy Management Editor will open in a new window.
  • Navigate to User Configuration > Policies > Administrative Templates > Control Panel > Personalization.
  • Individual settings can be modified by right-clicking and selecting Edit. There are radio buttons, and you can even add a comment if you desire. Modify the following settings:
    • Enable Enable screen saver
    • Set Screen saver timeout to 180 seconds
    • Enable Password protect the screen saver
    • Enable Prevent changing screen saver

Return to Group Policy management and apply the Sales GPO to Sales OU:

  • Right-click Sales OU, choose Link an Existing GPO..., and select Sales GPO from the list.

At this point, expand your Sales OU and select the Sales GPO link, click on the Settings tab and expand User Configuration (Enabled), Policies, Administrative Templates, and Control Panel/Personilizations to display all the changes you have made.

GPO Reports

You can export the settings report in HTML format. Simply right-click on any GPO and select Save Report.... You can open the HTML file in any browser.

Security and WMI Filtering

Select the Sales GPO, and observe the Security Filtering section under the Scope tab. You can specifically select users, groups, and computers that this GPO applies to. By default, GPOs apply to all Authenticated Users; in this case, all Authenticated Users that are in the Sales OU. Security Filtering enables targeting specific security groups to ensure only intended recipients receive the policy settings.

As an example, in this scenario, you may want to create separate GPOs for different groups of computers so that you can apply different settings. You may apply different settings to mobile computers (such as notebooks) versus specific desktop workstations in a secured room, or share workstations used for running projectors in meeting rooms.

Please note that security filtering modifies the GPO itself, so you must audit permissions applied to various objects to ensure they align with organizational policies and needs.

WMI filters can be created to target specific versions of OS, software, specific hardware configuration, or other computer attributes. GPO is applied only if the WMI query on the target system returns a match to the specified attributes.

GPO Backup and Restore

Since there are many settings, as best practice, you may want to create backups of your existing GPOs so you can restore/roll back in case of undesired outcomes. To back up a GPO, simply right-click on any GPO or the Group Policy Objects to back up one or all GPOs.

  • Back up your Sales GPO to C:\Software. In the description text box, enter today's date and time using the following format:
    • Sales GPO Backup YYYY-MM-DD HH-MM
  • You can explore the backup directory to see what was saved and what the file structure looks like. These backup directories are not simple to identify and manage manually just by looking at the files, unless you explore the XML code.
  • Launch the Restore from Backup... wizard by right-clicking the Sales GPO to verify your backup:
    • Click Next > on the first screen and select C:\Software as your Backup folder: on the second screen, and click Next >.
    • Select Sales GPO from the list, and click the View Settings... button. Microsoft Edge will open with the Sales GPO details in an HTML page.
    • Scroll down to User Configuration (Enabled) and expand Administrative Templates, and then Control Panel/Personalization by clicking the show link on the right side. You should observe all modifications you have made in the previous step.
  • You can close the browser window and either continue to restore, or just cancel out of the wizard.

Additionally, you can manage backups from the Group Policy Objects level:

  • Right-click on Group Policy Objects, and select Manage Backups....
  • You can browse to the backup directory, C:\Software, and your backup should be listed. You can view, delete, and restore backups from this window.

Viewing the GPO Precedence

Multiple GPOs may apply to the same OU or object. In case of overlapping settings and configurations, you can view the order of precedence to see which settings are applied to an object.

In Group Policy Management, select the Sales OU.

  • Observe the directly linked GPO under the Linked Group Policy Objects tab.
  • Open the Group Policy Inheritance tab and review which GPOs are applied to the OU and their location (scope).

Applying Baseline GPO

Now that you are familiar with the basics of the Group Policy Management utility, we will be exploring and applying security baseline recommendations from Microsoft.

  • Review the documentation for Microsoft Security baselines
  • Download the Microsoft Security Compliance Toolkit 1.0 for the latest version of Windows that is currently available.
    • There are additional tools available for download. These tools are not included in the OS specific packages and need to be downloaded and added separately.
      • Read Microsoft Security Compliance Toolkit - How to use to see what they are and what they are used for.

Extract the download to your host computer, open the Documentation directory and explore the content. At the time of writing, the latest Windows client security baseline toolkit was for Windows 11 version 26H2; however, you should download the latest available version. Open the included Excel file MS Security Baseline <Windows Version>.xls and explore all the recommended settings for various systems, such as firewall, users, and the general security template. For example, look for "Minimum password length" to see what Microsoft recommends. Alternatively, you can explore the GP Reports directory to view GPO reports in HTML format.

Importing and Applying Microsoft Baseline Security Compliance

  • On DC1-2017-####, save the Microsoft Baseline security for the latest Windows client under C:\Software using any method:
    • If your virtual network has access to the internet, you can download the baseline files directly to DC1-2017-#### from the Microsoft Download Center.
    • If you have VirtualBox Guest Additions installed on your server, you can transfer files using additional methods:
      • File drag and drop from host to guest
        • From the VM window, select Devices > Drag and Drop and enable the appropriate direction. Then open C:\Software in the guest and drag the extracted directory from your host into the explorer window in the guest.
      • Using VirtualBox Shared Folder
        • From the VM window, select Devices > Shared Folders > Shared Folders Settings..., and add a shared folder
        • For example, I share my Downloads folder: Click the add icon on the right, select the source folder path, enable Auto-mount checkbox, and optionally enable Make Machine-permanent or Male Global if desired. You will see the shared directory and a mapped network drive in your Windows VM:
  • Before you begin making any further changes, back up the current GPOs.
    • In Group Policy Management, right-click on Group Policy Objects and choose Back Up All.... Store the backup to any location you desire.
  • Create a new GPO object for each category of GPO that is included in the OS specific package you have downloaded:
    • Navigate to the GP Reports directory for the list of included GPOs in the package you have downloaded
    • Use this naming convention: ####-<GPO name> (#### is the last 4 digits of your student ID)
      • For example, from MS Security Baseline Windows 11 v26H2, I create GPOs with the following names:
        • ####-MSFT Internet Explorer 11 - Computer
        • ####-MSFT Internet Explorer 11 - User
        • ####-MSFT Windows 11 26H2 - BitLocker
        • ####-MSFT Windows 11 26H2 - Computer
        • ####-MSFT Windows 11 26H2 - Credential Guard
        • ####-MSFT Windows 11 26H2 - Defender Antivirus
        • ####-MSFT Windows 11 26H2 - Domain Security
        • ####-MSFT Windows 11 26H2 - User
    • Import settings into each GPO:
      • Right-click each GPO, choose Import Settings..., and follow the prompts to import settings from the GPO stored under C:\software\<package name>\GPOs. Repeat this process until you have all the GPOs imported.
