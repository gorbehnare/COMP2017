Lab 02 - Primary Domain Controller

In this lab, you will be creating a primary domain controller using AD DS, with DNS and DHCP serivices. The following procedure is to be followed on your DC1-2017-#### Server 2025 VM.

Preparations

Before Starting the VM

  • In VirtualBox, navigate to your Network and NAT Network, and disable the DHCP server.
  • Increase the memory on the DC1-2017-#### VM to 4096 MB, or if your host is memory constrained, set it to at least 3072 MB.
  • Now you can start the DC1-2017-#### VM and log in as Administrator.

Configure Network Interface

In Windows Server, open the settings and navigate to Network & Internet. Configure your Ethernet adapter with a static IP configuration as follows:

Setting Value
IP Address 172.16.0.10
Subnet Mask 255.255.0.0
Default Gateway 172.16.0.1
Preferred DNS Server 172.16.0.10

Verify your internet connectivity by opening the command line and using ping to verify a connection to a public IP address. You can use any public IP address such as 1.1.1.1 (Cloudflare DNS) or 8.8.8.8 (Google DNS).

Change the Computer Hostname

You can change the hostname using the Settings app in Windows under System, and using the Rename link under the current hostname.

  • Change your hostname to DC1-2017-#### (replace #### with your final four student-number digits).
  • Restart the server when prompted.

Installing AD DS, DNS, and DHCP Roles

Before you start installing server roles, validate your configuration from the previous step on DC1-2017-####:

  • Log in as Administrator, open PowerShell, and run ipconfig /all

  • Validate that the following information is correct:

    • Host Name
    • IPv4 Address
    • Subnet Mask
    • DNS Servers

  • Run ping to validate your system has an internet connection. For example: ping 1.1.1.1.

  • Take one or more SCREEN SHOTS showing all the information. Here is an example:

  • Proceed to install the AD DS and DNS roles using the Server Manager:

    • Server Manager → Manage → Add Roles and Features
    • Follow the Wizard to install the following roles:
      • Active Directory Domain Services
      • DHCP Server
      • DNS Server
    • Use the default administrative tools. Do not select additional features other than the default selection.
    • Complete installation as per the Wizard process, and wait for the installation to complete.

Promote to Domain Controller

Once the installation is complete, "Post-deployment Configuration" warnings will appear in the Server Manager interface via notification flags.

  • Click the notification flag and select Promote this server to a domain controller.
  • Select the Add a new forest radio button
  • Set root domain to comp2017-####.local where #### is the last 4 digits of your student ID.
  • set your Directory Service Restore Mode (DSRM) password to something that you can remember
  • Accept default settings for the rest of the wizard, select Install, and allow the server to reboot and apply the settings.
    After the reboot, you will need to log in as the domain administrator account by entering the domain before the username:
comp2017-####\administrator
comp2017-####\administrator

Configure DNS

In the Server Manager, click on Tools and select DNS. Select your server to adjust the following configuration:

  • Open the Forward Lookup Zone, right-click on your domain, comp2017-####.local, and select Properties

    • Under the General tab, set Dynamic updates: to Nonsecure and secure, and apply and close.

  • Open the Reverse Lookup Zone, and add a new zone:

    • Follow the wizards and select default options
    • Set the Network ID to 172.16.0 in the appropriate step.
    • Finish the wizard with default settings for the remaining steps

  • In the DNS Manager, expand both the Forward Lookup Zones and the Reverse Lookup Zones and take a SCREEN SHOT of the DNS Manager window. Here is an example:

Configure DHCP

In the Server Manager, click on Tools, select DHCP, and expand your server FQDN (dc1-2017-####.comp2017-####.local).

  • Select IPv4 and either right-click or click on More Actions on the right to find New Scope...
  • Use the following Scope Configuration:
    Setting Value
    Scope Name comp2017-####
    Start IP 172.16.0.160
    End IP 172.16.0.190
    Router (Default Gateway) 172.16.0.1
  • Accept default options for Exclusions, Delay, Lease Duration, DNS and WINS.
  • Select the Yes, I want to activate this scope now radio button and finish the wizard.
  • Authorize the DHCP Server by selecting dc1-2017-####.comp2017-####.local and Authorize in the context menu for More Actions or Right-Clicking.
  • In the DHCP window, expand the IPv4 on the left to see your scope and take a SCREEN SHOT of the DHCP window. Make sure the FQDN of your server is visible. Here is an example:
