Lab 02 - Windows Hosts

You will be configuring the rest of the systems that are required for our lab environment. These hosts will be used for future assignments. Before you start this lab, you must have already completed the previous labs. You should already have the NAT Network with freshly sysprep and cloned VMs connected, and your domain controller (DC1-2017-####) must be correctly configured and running. You will not be able to complete the lab procedures if any of these components are missing or not fully operational.

Before you proceed, start your Primary Domain Controller, DC1-2017-####, and make sure that this server is up and running for the duration of this lab.

Be sure to replace all #### with the last 4 digits of your student ID. Once you start each system for the first time, proceed with entering your product key, creating a local administrator account password, and choosing to only send Required only diagnostics data to Microsoft.

Configure Member Server SVR1

Start your SVR1-2017-#### VM, and initialize and configure the system as follows.

  • Apply the following static IPv4 Configuration to this system:
Setting Value
IP Address 172.16.0.21
Subnet Mask 255.255.0.0
Default Gateway Blank
Preferred DNS Server 172.16.0.10
DNS over HTTPS Off
  • Rename the host and enroll it into the domain:
Setting Value
Computer Name SVR1-2017-####
Domain comp2017-####.local
  • The quickest way to change these configurations in Windows Server is to use the Server Manager and navigate to the Local Server on the left side.
    • You can change the hostname, domain membership, and other settings such as time zone in the "PROPERTIES" section on the same screen.
    • Sometimes you will have to hit the "Refresh" button at the top to see changes immediately.
    • You will be prompted to enter your Administrator credentials for some changes
  • Restart the server and log in as domain administrator comp2017-####\Administrator by clicking on Other User.

Open the Server Manager and the Local Server window and take a SCREENSHOT. Make sure that the following information is fully visible:

  • Computer Name
  • Domain
  • Network Setting
  • Firewall Status

  • Restart the server and log in as the local Administrator account.

Install Active Directory and DNS on TREY

  • On your TREY-2017-####, install the AD DS and DNS roles using Server Manager:
    • Server Manager → Manage → Add Roles and Features
    • Follow the Wizard to install the following roles:
      • Active Directory Domain Services
      • DNS Server
    • Use the default administrative tools. Do not select additional features other than the default selection.
    • Complete installation as per the Wizard process, and wait for the installation to complete
  • Promote Server to Domain Controller:
    • On the notification flag, click the Promote this server to a domain controller text.
    • Choose the Add a new forest radio button.
    • Root domain: federatedlab.local.
    • Accept default settings for the rest of the wizard, select Install, and allow the server to reboot and apply the settings.
  • Reboot the server when prompted.
  • Log in to the server using the domain administrator account.

DNS Configuration on TREY

In the Server Manager, click on Tools and select DNS. Select your server to adjust the following configuration:

  • Open the Forward Lookup Zone, right-click on your domain, federatedlab.local, and select Properties
    • Under the General tab, set Dynamic updates: to Nonsecure and secure, and apply and close.
  • Open the Reverse Lookup Zone, and add a new zone:
    • Follow the wizards and select default options
    • Set the Network ID to 172.16 in the appropriate step.
    • Finish the wizard with default settings for the remaining steps

Open the Server Manager and the Local Server window and take a SCREENSHOT. Make sure that the following information is fully visible:

  • Computer Name
  • Domain
  • Network Setting
  • Firewall Status
  • You can shut down the server at this point if desired.
