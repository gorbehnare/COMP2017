    • Use the Advanced Sharing... button and set the Shared Name to SalesData
    • Use the Permissions button and under Share Permissions add the following groups:

      • Sales_Managers
        • Do not forget to use the Apply buttons to apply your settings for each step. Validate each step by opening each window again to ensure your configurations are applied and saved.
